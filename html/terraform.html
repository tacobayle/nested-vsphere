Terraform Demo


Create a VS in automation tenant - commands to use from the external gateway 

cd ~/automation/tfAviVsIpamDns
# display variables
more app.tf
more infra.json
terraform init
terraform apply -auto-approve -var-file=./infra.json -var-file=/home/ubuntu/.creds.json
Destroy a VS - commands to use from the external gateway 

cd ~/automation/tfAviVsIpamDns
terraform destroy -auto-approve -var-file=./infra.json -var-file=/home/ubuntu/.creds.json
